A desk display for the things worth glancing at: what's running, what needs attention, what's next. The visual direction borrows from sci-fi interface kits like the [Orbit Sci-Fi UI Kit](https://dribbble.com/shots/23942591-Orbit-Sci-Fi-UI-Kit).

## Empty states matter

When there's nothing to review, the screen says so — politely, in rhyme:

```text
No PRs in sight, everything seems all right.
No pull requests to unfold, everything's under control.
PR queue is clear, no need to fear.
No open pull requests, development rests.
PRs all done, time for some fun.
Pull requests all closed, codebase composed.
```
